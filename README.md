# Котопрыг

Аркадный платформер про кота на крышах. Играть: https://notfayk.github.io/kotoprig/

- 4 мира (ночь, закат, зима, гроза) по 3 уровня, дальше сложность продолжает расти
- Бонусы: мята (кот-гигант), молния (скорость), перо (двойной прыжок), магнит, клубок (неуязвимость), сердце (+1 жизнь)
- Враги: мыши, голуби, ежи, собаки; движущиеся платформы и ветхие мостики
- Гардероб: 8 костюмов, открываются за очки из всех игр
- Прогресс сохраняется в браузере: игра продолжается с последнего открытого мира (N — новая игра с 1-1)
- Управление: ← → бег, Пробел прыжок, C костюм, P пауза, M звук, D демо

# Котоклинок

Слешер-роглайт про кота в сапогах на драконе. Играть: https://notfayk.github.io/kotoprig/knight/

- Арена, волны врагов, босс каждые 5 уровней; проиграл — забег сначала
- 28 навыков по 5 уровней и 14 связок; карты выпадают за опыт, сундуки и пройденные уровни
- Враги: мышата, крысы, суперкрысы, летучие мыши, лучники, ежи-катуны, подрывники, бронепсы, шаманы; боссы: Крысиный король, Пёс-великан, Сова-колдунья
- Управление: WASD бег, J/Пробел/мышь удар, Shift/K рывок, F огонь дракона (10 с, раз за уровень), P пауза, 1-3 выбор карты
